Assistente:
Para um projeto novo, o prefixo mais adequado e geralmente:
- feat: quando voce esta criando uma funcionalidade inicial ou o primeiro conjunto de recursos do projeto
Exemplo:
- feat: initial project setup
Tambem pode ser usado:
- chore: para setup inicial, configuracao, arquivos base e organizacao
Exemplo:
- chore: initialize project structure
Resumo:
- use feat para criar algo novo
- use chore para configurar/estruturar o projeto
